¿Cómo preparar una plantilla?

  1. Descarga la plantilla actual (si existe) o crea un documento Word nuevo.
  2. Usa las variables indicadas abajo dentro del documento usando la sintaxis ${VAR}.
  3. Para filas que se repiten, asegúrate de que la primera fila de la tabla contenga las variables y de que no haya más de una fila de datos (el sistema clona esa fila automáticamente).
  4. Guarda como .docx y súbelo aquí.
